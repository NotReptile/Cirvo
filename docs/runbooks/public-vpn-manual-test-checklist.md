# RuCord manual test checklist: static IP + remote VPN client

Сценарий проверки: основной компьютер/сервер работает через чистый интернет со
статическим IP, второй компьютер подключается из другой страны через VPN.

Актуальный установщик для проверки:
`apps/desktop/src-tauri/target/release/bundle/nsis/RuCord_0.1.0_x64-setup.exe`

## Данные теста

- Дата проверки:
- Публичный IP или домен сервера:
- Страна/регион второго ПК:
- VPN-провайдер/страна выхода:
- Версия клиента на первом ПК:
- Версия клиента на втором ПК:
- Аккаунт 1:
- Аккаунт 2:

Мои заметки:



## 1. Установка актуального билда

Проверить:

- установщик запускается на обоих ПК;
- Windows не блокирует установку неожиданным образом;
- приложение открывается после установки;
- предыдущая версия, если она была, корректно заменяется новой.

Мои заметки:



## 2. Доступность сервера с публичного интернета

Проверить:

- сервер доступен по публичному IP или домену;
- нужные порты открыты снаружи;
- firewall на серверном ПК не режет входящие подключения;
- клиент с VPN-сети не получает timeout/refused при подключении.

Мои заметки:



## 3. Первый запуск и выбор сервера

Проверить:

- клиент позволяет указать нужный endpoint;
- endpoint сохраняется после перезапуска;
- ошибка при неверном endpoint понятная;
- после возврата правильного endpoint подключение восстанавливается.

Мои заметки:



## 4. Регистрация и вход

Проверить:

- первый аккаунт входит с серверного ПК;
- второй аккаунт входит с удаленного ПК через VPN;
- повторный вход после закрытия приложения работает;
- logout/login не ломает сессию и список данных.

Мои заметки:



## 5. Workspace и каналы

Проверить:

- создание workspace;
- создание текстового канала;
- создание голосового канала;
- переключение между каналами на обоих клиентах;
- состояние каналов одинаково видно с двух ПК.

Мои заметки:



## 6. Приглашения и подключение второго пользователя

Проверить:

- создание invite;
- копирование/передача invite на второй ПК;
- вход второго пользователя по invite;
- пользователь появляется в нужном workspace/channel;
- невалидный или уже отозванный invite обрабатывается корректно.

Мои заметки:



## 7. Текстовые сообщения

Проверить:

- отправка сообщений с первого ПК на второй;
- отправка сообщений со второго ПК на первый;
- порядок сообщений одинаковый у обоих пользователей;
- длинные сообщения и ошибки лимитов отображаются корректно;
- сообщения сохраняются после перезапуска клиента.

Мои заметки:



## 8. Realtime, presence и переподключение

Проверить:

- online/offline-статусы обновляются без ручного refresh;
- новое сообщение появляется на втором ПК без перезагрузки;
- краткий разрыв VPN приводит к переподключению;
- после восстановления сети сообщения и состояние не теряются.

Мои заметки:



## 9. Файлы и медиа

Проверить:

- загрузка небольшого файла;
- загрузка изображения;
- скачивание файла на втором ПК;
- preview/lightbox для изображения, если доступен;
- ошибка при слишком большом файле понятная.

Мои заметки:



## 10. Голосовой канал

Проверить:

- оба пользователя заходят в один голосовой канал;
- микрофон первого ПК слышен на втором;
- микрофон второго ПК слышен на первом;
- mute/unmute работает;
- выход из канала освобождает состояние участника;
- задержка и качество приемлемы через VPN.

Мои заметки:



## 11. Видео и настройки устройств

Проверить:

- выбор микрофона;
- выбор камеры;
- включение/выключение камеры;
- смена устройства во время сессии;
- приложение корректно реагирует на отсутствие камеры или запрет доступа.

Мои заметки:



## 12. Screen share

Проверить:

- старт демонстрации экрана;
- выбор окна или монитора;
- удаленный пользователь видит демонстрацию;
- остановка демонстрации не роняет голосовой канал;
- повторный старт после остановки работает.

Мои заметки:



## 13. NAT/VPN/WebRTC поведение

Проверить:

- звонок соединяется, когда второй ПК находится за VPN;
- ICE/TURN diagnostics не показывает критичных ошибок;
- при смене VPN-локации поведение понятно;
- если media не соединяется, записать тип NAT/VPN и симптомы.

Мои заметки:



## 14. Права, роли и ограничения

Проверить:

- базовая роль пользователя не получает лишние админ-действия;
- channel permissions применяются к удаленному пользователю;
- запрет отправки сообщений реально блокирует отправку;
- запрет входа в голосовой канал реально блокирует вход.

Мои заметки:



## 15. Админка и диагностика сервера

Проверить:

- админ видит server metrics;
- список пользователей загружается;
- ban/unban пользователя работает;
- настройки лимитов сохраняются;
- health/ready endpoints доступны в ожидаемом виде.

Мои заметки:



## 16. Перезапуск приложения и сервера

Проверить:

- клиент восстанавливается после перезапуска;
- серверный рестарт не оставляет клиента в вечном loading;
- после рестарта оба клиента снова видят workspace/channels/messages;
- активные голосовые/медиа-сессии завершаются или восстанавливаются понятно.

Мои заметки:



## 17. Производительность и стабильность

Проверить:

- приложение не зависает при длительной сессии;
- CPU/RAM на серверном ПК не растут бесконечно;
- CPU/RAM на удаленном ПК приемлемы во время voice/screen share;
- UI остается отзывчивым при плохом VPN-канале.

Мои заметки:



## 18. Логи и артефакты проверки

Проверить:

- где лежат клиентские логи;
- где лежат серверные логи;
- есть ли ошибки в логах после обычного сценария;
- приложены скриншоты/логи для найденных проблем.
