# Technical Wiki

- `architecture/overview.md` - system boundaries and runtime composition.
- `architecture/monorepo-structure.md` - repository structure and responsibility map.
- `architecture/backend-modules.md` - internal `core-api` modules and dependency rules.
- `architecture/client-architecture.md` - desktop client layer model.
- `architecture/realtime-and-calls.md` - realtime, signaling and media boundaries.
- `database/domain-model.md` - first iteration data model.
- `database/migrations-strategy.md` - migration and bootstrap policy.
- `api/overview.md` - HTTP contract strategy.
- `security/overview.md` - auth, sessions, permissions and secrets policy.
- `deployment/environments.md` - local, single-node and internet-facing environments.
- `runbooks/local-development.md` - local development runbook.
- `runbooks/single-node.md` - single-node deployment runbook.
- `runbooks/internet-facing.md` - public deployment runbook.
- `runbooks/backup-and-restore.md` - backup scope and restore baseline.
- `runbooks/diagnostics.md` - basic diagnostics flow.
- `engineering/conventions.md` - repository and engineering conventions.
- `adr/` - architecture decision records.
