# Проверка длинных каналов

`npm --workspace apps/desktop run test:browser` запускает повторяемые замеры
в Chromium: 50, 1500 и 3000 сообщений, первый render и пять повторов. Первый
замер канала выполняется после пустого shell, как при bootstrap приложения;
повторные используют существующий DOM и кэши сообщений.
Их нужно сравнивать отдельно. Результаты пишутся в
локальный игнорируемый файл `current.json`. Переменная `CIRVO_PERF_BASELINE=1`
сохраняет исходный замер в `baseline.json`.

QA-интерфейс существует только в Vite dev. В release-сборке он отсутствует.
`seed-qa.sql` используется только на отдельной QA-базе; штатное имя боевой
базы блокируется. Не запускайте этот скрипт на пользовательских данных.
